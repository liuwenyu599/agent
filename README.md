# 云法智办 · 司法智能办公写作系统

> 面向司法行政办公场景的智能公文写作平台。以 **多智能体（Multi-Agent）+ RAG** 为核心，打通「写作需求 → 知识检索 → 内容生成 → 格式校验 → 文档导出」的自动化流程，显著降低基层公文写作门槛，提升成稿质量与一致性。

> ⚠️ 说明：本项目文档为**脱敏后的架构与能力说明**，不含任何内网地址、账号或敏感业务数据。代码与资料已做合规处理。

---

## 一、项目背景

基层司法行政单位日常需处理大量公文（通知、函、报告、方案等），传统写作存在 **格式不规范、政策依据难查、重复劳动多** 等痛点。本项目基于大语言模型构建智能写作工作台，将业务资料与公文范式沉淀为可检索知识，由多个协作 Agent 完成从需求理解到成稿导出的端到端流程，已在多个业务科室开展试点。

## 二、技术栈

| 领域       | 选型                                                     |
| -------- | ------------------------------------------------------ |
| Agent 编排 | **LangGraph**（任务调度 / 条件边 / 状态管理）、Function Calling 工具集成 |
| 检索增强     | **RAG**：文档切分 + 向量检索 + 混合检索，支持检索来源标注                    |
| 后端服务     | **FastAPI**（接口开发 / 模型服务封装）、Pydantic、Alembic            |
| 模型推理     | 本地大模型服务池（vLLM 类推理栈）、昇腾推理卡                              |
| 数据持久化    | PostgreSQL + 向量检索                                      |
| 工程部署     | **Docker** 容器化、Docker Compose 编排                       |
| 桌面端      | Kotlin Compose Desktop（配套客户端）                          |
| 质量保障     | pytest 单元测试（700+ 用例）                                   |

## 四、核心功能

### 1. 智能写作台（Multi-Agent）

围绕公文生成任务，拆解为 **检索 / 内容生成 / 格式校验** 等职责明确的 Agent，由 LangGraph 统一编排：

- **检索 Agent**：根据写作意图从知识库检索政策依据与范文范式，返回带来源标注的上下文；
- **生成 Agent**：结合检索上下文与用户需求生成公文正文，支持分段生成与修订；
- **校验 Agent**：对成稿做格式规范与质量门（Quality Gate）校验，不达标则退回修订；
- 跨 Agent 的 **状态（State）与上下文传递** 由编排层统一管理，支持条件分支与失败兜底。

### 2. RAG 知识增强

- 将司法业务资料与公文模板入库，经过文档解析、切分、向量化构建检索索引；
- 支持 **混合检索**（向量 + 关键词）并对多路召回结果做分数融合；
- 检索结果可 **溯源标注**，降低对模型参数知识的依赖，提升成稿可信度。

### 3. 格式校验与质量门

- 针对公文版式、套语、落款、日期等要素做结构化校验；
- 质量门对正文长度、关键槽位（主送单位 / 落款单位 / 落款日期）做一致性检查，拦截明显硬伤。

### 4. 文档导出

- 支持公文成稿导出为常用办公格式（Word / PDF 等），保持版式规范。

### 5. 知识网络（Knowledge Graph）

- 对业务实体与关系做结构化沉淀，辅助检索与关联推荐。

### 6. PPT 智能生成（扩展能力）

- 基于对话/文档自动生成汇报型 PPT，覆盖提纲、版式与导出。

### 7. 管理后台

- 账号与组织架构（identity / organization）、操作审计（audit）等支撑能力。

## 七、本地开发与部署

### 后端（FastAPI）

```bash
cd server
pip install -r requirements-server.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# 接口文档：http://localhost:8000/docs
```

### 数据库迁移

```bash
cd server
alembic upgrade head
```

### 容器化部署

```bash
# 生产以镜像构建方式部署（代码烤入镜像），非目录挂载
docker compose up -d
```

> 实际部署运行于政务内网环境，需配合内网模型服务池与数据库容器。
