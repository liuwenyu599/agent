# PPT 模板：自取、处理与验收

> 不走招标/批量采购，模板要自己找来、自己处理成系统可用形态。本文分四部分：**来源与授权边界 → 收集红线 → 处理流程（工具已备好）→ 验收标准**。图库要求在文末。
>
> 所有下载和处理都在**开发机**完成（生产内网禁出网），成品随镜像进内网。

## 一、来源：按优先级排

### 1. 单位内部存量 PPT（最优，优先做）

历史汇报、获奖课件、内部培训材料。优点：**授权零风险**（本单位自己的作品）、风格贴合司法行政业务、领导看着眼熟。

挑选标准：近两年的；被夸过"好看"的那几份；页型全的（封面/章节/要点/图文/数据都有）。

`deliverables/` 里已有的几份"云法智办"汇报 PPT 就是现成候选，可以直接走处理流程试第一套。

### 2. 免费可商用模板

Office/WPS 内置模板库、官方免费资源、GitHub 上的开源 deck。**必须逐份打开许可证原文**："免费下载"≠"可商用"≠"允许修改后再分发"，三个条件都要满足才能用。

### 3. 付费模板（谨慎）

注意授权类型：多数素材站的授权是**单用户、单项目使用**。把模板放进多用户自动生成平台，属于"修改后提供给第三方使用"，个人授权在合规上有缺口——这不是技术问题，需要业务/法务拍板。

稳妥用法：付费模板只当**设计参考**，用 PowerPoint 照它的版式风格仿制一套（版式布局可参考，装饰图形是版权表达，不要直接搬运原图）。

## 二、收集时的红线（碰到的直接放弃，别花处理时间）

| 红线 | 原因 |
|---|---|
| 不是 16:9（4:3、16:10） | 系统按 13.333×7.5in 固定坐标填充；等比拉伸会把圆形变椭圆，必须人工重排，成本高于重新做 |
| 整页是图片、文字烘焙在图里 | 无文本框的版式系统直接跳过，等于白买 |
| SmartArt | 系统不解析其内部文本 |
| 加密/受保护文件 | 解析直接失败 |
| 依赖在线字体或外链图片 | 内网无外网，全部失效 |
| 一张示例照片在每页重复 | 会被判成固定装饰，出稿每页都挂着它 |

## 三、处理流程（工具已备好，全机械操作）

工具：`deploy/prepare_ppt_template.py`。只做机械改造（删页、加占位符、图片锚点、统一字体），**不重排版面**。

```bash
# 第 1 步：诊断（不改文件），看比例/页数/每页文本框和图片分布
python deploy/prepare_ppt_template.py 原模板.pptx

# 第 2 步：处理（第 2、6 页是目录和纯图片页时删掉；页码按原始页算）
python deploy/prepare_ppt_template.py 原模板.pptx --out 处理后.pptx \
    --drop-pages 2,6 \
    --title-tokens --point-tokens \
    --image-anchors --image-pages 5 \
    --font 思源黑体

# 第 3 步：体检
python deploy/check_ppt_template.py 处理后.pptx

# 第 4 步：试填 + 人眼检查（见第四节末尾）
```

各参数做什么：

- **`--drop-pages 2,9`**：删目录页/结束页/示例页。系统不强制使用目录和结束页，但留着会占版式库、可能被误选。
- **`--title-tokens`**：每页最大字号的文本框 → `{{title}}`，封面次大 → `{{subtitle}}`。封面剩余文本框不动，工具会列出请你人工确认（可能是单位落款）。
- **`--point-tokens`**：其余文本框按阅读顺序（从上到下、从左到右）→ `{{point1}}..{{pointN}}`。
- **`--image-anchors`**：每页**唯一**的图片 → 等尺寸 `{{image}}` 文本框锚点。出现在 ≥60% 页面的图（背景带、logo）自动跳过；多图页用 `--image-pages 3,5` 指定取面积最大的那张。
- **`--font 思源黑体`**：统一全文中西文字体，**同时改写主题字体**（系统读模板字体读的是 theme，只改文字不生效）。

**不加占位符也能用**：系统按"最大字号=标题、其余文本框按阅读顺序=正文"自动识别。占位符的价值是**精确控制**——卡片页（`{{cardN_label}}/{{cardN_value}}`）、时间轴页（`{{timeN}}/{{eventN}}`）、图片页（`{{image}}`）这三类必须手工加，普通要点页可省。

## 四、验收标准（无论来源，处理完都按这个过）

### 4.1 文件与页型

- **16:9（13.333×7.5 英寸），容差 ±2%**——超差系统直接拒收；
- 每套 8~12 页（<6 页拒收），至少覆盖：封面、章节页、正文要点、图文、数据/对比、流程或时间轴、总结；
- **正文页至少四种不同几何结构**。注意：系统按元素位置去重，坐标精度约 1/6 页——只是换配色或微调位置的页会被合并成一个版式。"四种不同"需要满足：文本框数量不同，或任一元素位移超过约 1/6 页，或分栏结构不同（左右两栏→上下两段→三卡片→单栏通栏）。

### 4.2 占位符白名单（系统只认这些）

| 用途 | 占位符 | 说明 |
|---|---|---|
| 标题 | `{{title}}` | 每张正文页必有 |
| 副标题 | `{{subtitle}}` | 封面 |
| 正文要点 | `{{point1}}`…`{{point6}}` | 顺序对应第 1~N 条 |
| 文字卡片 | `{{card1_title}}` `{{card1_body}}` | 标题+说明文字的卡片 |
| **数据卡片** | `{{card1_label}}` `{{card1_value}}` | **指标名+数值**，数字成果页必用这个 |
| 时间轴 | `{{time1}}` `{{event1}}` | 成对使用 |
| 图片位 | `{{image}}` | 空文本框当锚点，系统按框的矩形插图 |
| 图表位 | `{{chart}}` | 系统在该区域生成原生可编辑图表 |

- 每页要点槽位 **3~6 个，宁多勿少**：内容条数多于槽位时**超出的内容会静默丢失**；槽位多于内容时替换为空文本（安全）。
- 数据卡不要用 `title/body`：系统内部 title≡label、body≡value，放在大小字位上会颠倒（指标名占大字位、数值挤小字位）。
- 流程页用 `{{point1}}..{{pointN}}` 按步骤顺序对应，否则步骤被拼成"第1步：…"整段。

### 4.3 文字与装饰的边界

- 系统把"≥60% 页面同一位置重复出现"的元素判为装饰保留（logo/页脚靠这条保护）；
- 但**文字**只有"字号 ≤14pt 且 ≤15 字"才可能被判装饰——所以**想被替换的文字不要用小字号**，否则示例字会永久印进成品；
- 页脚、页码、单位落款这类固定短文本可以每页重复。

### 4.4 其他

- 组合（Group）允许，系统递归解析；但不要整页塞进一个大组合（文字能换、版式无法局部调整）；
- 字体：思源黑体/Noto Sans CJK 优先；微软雅黑、等线、黑体、宋体、方正兰亭黑、HarmonyOS Sans 可用；不要 Calibri/Arial 当中文主字体；
- 单页形状 <80 个；装饰尽量合并。

### 4.5 最终人工三看（工具过了也要做）

用一份**真实长短混合**的汇报内容生成一版，打开成品检查：

1. **文字替换完整**：无示例字残留、无内容丢失；内容超过版式容量时会逐页使用可读版式并给出提示，若频繁出现则应退回模板；
2. **图片合适**：`{{image}}` 位插入的图不变形、不遮挡；
3. **页面不溢出**：正文远长于示例时组内文本框会挤压，重点看组合页。

## 五、图库首批内容

优先使用单位自摄或单独取得授权的图片：法治宣传、调解、会议培训、办公服务、基层走访、成果展示。

- 每张附：名称、场景说明、分类、来源、授权说明；
- **不要来源不明的人像、徽章、地图或涉密场所照片**；
- JPG/PNG，长边 ≥1600px，单张 ≤3MB，横图优先（16:9 或 3:2）；
- 图库由管理员上架、普通用户选用，**只把用户本次选用的图片用于本次生成**。

> 公共图库功能随本期上线。此前系统只有个人素材库（自传 + 按标题语义自动配图）。图库内容可按本节要求先行准备。

## 附：条款与系统实现的对应关系（内部参考）

| 条款 | 实现依据 |
|---|---|
| 16:9 容差 ±2% | `validate_learned_template`：`abs(w/h - 16/9) > 0.02` 拒收 |
| 版式去重精度约 1/6 页 | `_layout_signature`：坐标 `round(x*6)` |
| 正文版式 ≥4 | 体检工具 `content_layouts < 3` 才 FAIL（四种需人工数） |
| 页数 8~12 | 体检工具 `total < 6` FAIL |
| 占位符白名单 | 正则 `\{\{([a-zA-Z][a-zA-Z0-9_]*)\}\}`；取值 `_template_token_values` |
| title≡label / body≡value | `values[f"card{i}_title"] = values[f"card{i}_label"]` 等 |
| `{{image}}` 锚点 | 填充循环 `"image" in keys` → 按框矩形 `add_picture` 删框 |
| 多余要点丢失 | `available_points` 只取未被 token 占用的序号 |
| 装饰判定 | `_text_is_decorative`（≤14pt 且 ≤15 字）+ `_mark_fixed`（≥60% 重复） |
| 组合递归 | `_iter_shapes` 按 `chOff/chExt` 换算页面坐标 |
| 字体读主题 | `_extract_style` 读 `ppt/theme/themeN.xml` 的 `a:ea`/`a:latin` |
