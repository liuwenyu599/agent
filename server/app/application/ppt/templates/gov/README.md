# 默认政务 PPT 模板

这里是司法局 PPT 链路的默认“严格套模板”入口。

当前默认模板 ID：`gov_report_red`。

运行策略：

1. 正常情况先走 PPTAgent“AI 智能设计”；
2. 服务端自动检查页数、封面越界和明显中文字体异常；
3. AI 智能设计自动重试一次仍不合格时，切换到严格模板渲染；
4. 用户未选择模板时，严格模板渲染使用内置 `gov_report_red`；
5. 用户上传并选择了模板时，严格模板渲染优先使用该模板的原始 pptx 与已学习版式库。

本目录作为后续固定政务母版文件的落点。当前不重复存放一份二进制 pptx，
避免与 `ppt_engine.BUILTIN_TEMPLATES` 的权威配置产生双份来源。
