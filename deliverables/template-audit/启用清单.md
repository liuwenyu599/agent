# 模板启用清单（2026-11-05 体检定稿）

体检方式：每套模板用同一份 12 页样稿（封面/目录/章节/正文×N/结尾）实际渲染，
逐页做确定性几何审计（越界/溢出/重叠/遮挡/残留 token/示例文字/字号下限），
问题页附预览图。报告全文见 `report.md`，逐套产物在同名目录。

> ⚠ 生成质量（大纲/文案）依赖 35B 模型，开发机无法连通 `10.128.85.133:8010`，
> 本清单只对**版式可用性**下结论，不代表真实模型生成质量。

## 本次体检修掉的引擎问题（修复后 PASS 数从 11 → 17）

1. **旋转竖排框**（rot=90°/270°）此前不识别：目录第 3 条被塞进旋转侧栏框、
   正常胶囊反而空着。`_shape_is_vertical` / `_is_vertical_decor_slot` / schema 均已补 rot 判定。
2. **模板小字槽（9pt）塞正文后仍 9pt**：闸门按 max(14,·) 度量保证 13pt 可容，
   填充却不放大字号。新增 `_raise_tiny_body_text`：写入内容后提升到 13pt（装不下保持原字号）。
3. 审计器自身两处误报修正（细条出血装饰、嵌套框按文字实际区域判重叠）。
