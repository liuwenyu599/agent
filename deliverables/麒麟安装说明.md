# 云法智办客户端 · 麒麟安装说明

安装包：`yunfazhiban_1.1.0-1_amd64-kylin.deb`（99.2 MB，自带 JRE，无需另装 Java）

> 客户端本身不依赖 Python。若在银河麒麟机器上同时部署服务端，智能写作多智能体功能要求 **Python 3.11 或更高版本**；低于 3.11 时不得开启 `WRITING_AGENT_GRAPH_ENABLED`。部署前执行 `python3 --version` 核对版本。Docker 部署使用项目内的 Python 3.11 镜像，无需额外处理。

---

## 一、传到机器上

任选一种：

| 方式 | 操作 |
|---|---|
| U 盘 | 拷贝 `yunfazhiban_1.1.0-1_amd64-kylin.deb` 到 U 盘，插到麒麟机器，复制到`~/` |
| 内网传输 | 从能访问该机器的机器执行 `scp yunfazhiban_1.1.0-1_amd64-kylin.deb test@<机器IP>:~/` |
| 共享目录 | 若已挂载内网共享，直接从共享路径执行安装命令 |

装完后先确认文件在：

```bash
ls -lh ~/yunfazhiban_1.1.0-1_amd64-kylin.deb
```

## 二、安装

### 常规安装

```bash
cd ~
sudo dpkg -i yunfazhiban_1.1.0-1_amd64-kylin.deb
```

### 如果报「依赖未满足」

安装包声明了 7 个系统库。**`libbrotli1` 在部分麒麟版本里没有**（较新的 Ubuntu 才有），它只影响字体压缩，不是必需项：

```bash
# 方案 A：让 apt 修（能拉到就自动补齐）
sudo dpkg -i yunfazhiban_1.1.0-1_amd64-kylin.deb
sudo apt-get install -f

# 方案 B：忽略该依赖强制安装（确认 libpng16 已存在时用这个）
dpkg -l | grep libpng16        # 应看到 libpng16-16
sudo dpkg -i --force-depends yunfazhiban_1.1.0-1_amd64.deb
```

### 确认装上了

```bash
dpkg -l | grep yunfazhiban
# 期望：ii  yunfazhiban  1.1.0-1  amd64  白云区司法局智慧办公平台
```

## 三、配置服务器地址（**必做**）

客户端默认连`127.0.0.1:8000`，必须改成生产地址：

```bash
nano ~/JudicialAIDesktop/server.json
```

改成：

```json
{
  "baseUrl": "http://10.128.85.133:8000",
  "connectTimeoutMillis": 10000,
  "requestTimeoutMillis": 120000
}
```

> 路径说明：Linux 下没有 `%APPDATA%`，所以配置落在用户主目录下的 `JudicialAIDesktop/`。

**验证地址可达**（返回 200 即正常）：

```bash
curl -o /dev/null -s -w '%{http_code}\n' http://10.128.85.133:8000/docs
```

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 启动后界面空白 | 记录 `uname -m` 与显卡型号，反馈即可；先试 `SKIKO_RENDER_API=SOFTWARE yunfazhiban` |
| 提示连不上服务器 | 检查 `server.json` 的 `baseUrl`，再 `curl` 验证 |
| 菜单里找不到图标 | `ls /usr/share/applications/ | grep yunfazhiban`，可手动创建 |
| 启动时报缺库 | `sudo apt-get install -f` 补齐 |

## 六、卸载

```bash
sudo dpkg -r yunfazhiban# 保留配置
sudo dpkg -P yunfazhiban           # 完全删除
```

用户配置在 `~/JudicialAIDesktop/`，如需清空：

```bash
rm -rf ~/JudicialAIDesktop
```
