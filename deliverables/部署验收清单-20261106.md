## 模块一：历史顽疾（缩略图与生成状态）

### 1a. 生成完毕缩略图全部显示
- **测**：点生成，等状态变 DONE（5/5），看左侧所有页面缩略图。
- **已具备**：`PptAsyncWorkbench.kt:173` —— `refreshKey = job.status`，转入 DONE 时窗口内所有缩略图经 `rememberServerImage` 强制重发请求。
- **若有白板/黑块，按序查**：
  1. 服务器日志 `grep "PPT 逐页预览降级" /data/justice/logs/server.log` → 出现即镜像缺 `libreoffice`/`poppler-utils`（Dockerfile 已装，出现说明用了旧镜像）；
  2. `ls /data/justice/ppt/<doc_id>/preview/` 有无 `pg-*.png`；无则看同日志 `预览图生成失败` 行；
  3. 缩略图有文件但前端不显示 → 前端 `refreshKey` 问题，截图反馈。

### 1b. 假流式 / AI 状态持续更新
- **已具备**：大纲流式 SSE 有 6+ 条 stage 事件（理解材料 → 知识库检索 → 梳理结构 → 图库挑图 → 内容密度检查 → 图示生成 → 保存），渲染阶段 `job_phase` 流转 submitting → designing → succeeded。
- **如实预期**：正式本地链路的**渲染阶段没有逐页进度**（逐页 scan_progress 只存在于已退役的远程 PPTAgent 链路）；本地渲染中 pptx 拼装是秒级，主要等待是 soffice 出预览图（10-30 秒），此间状态停在 designing 属正常。
- **判据**：大纲阶段应看到状态文字**至少变化 3 次**；若从头到尾一条「生成中」不动，记录 doc_id 与时间点反馈。

## 模块二：版式多样化

- **提示词**：`做一份司法局年度工作总结及下一步计划的汇报。`
- **语义主题**：预期命中 `summary_brown`（总结汇报→棕红）。验证：生成的 PPT 主色应为棕红系，不是深蓝。若仍是深蓝，查生成日志里 outline 的 `style` 字段是否输出（`grep "style" 日志`）。
- **视觉多样性**：6 页稿预期 4-6 种版式（总结类常见：三卡 / 时间轴 / 双栏 / 单句结论 / 要点）。全篇同版式出现 ≤2 次（均衡惩罚已生效）。
- **大纲干净度**：要点应为完整句、无「高度重视」式空话；通知/总结类字数收敛由质量门负责。目测每页要点 ≤4 条、每条 ≤40 字为合格。

## 模块三：图表与流程图（原生可编辑引擎）

- **测**：提示词里明确含流程（如「汇报审批流程」）与对比数据（如「两年数据对比」）。
- **画图**：下载 PPTX 在 WPS 打开，图形必须是可点击的原生形状（能选中、能改色），不是文本堆。
- **样式**：点选图形——圆角、底部淡阴影、灰色 2pt 加粗线条。
- **引擎确认**（服务器执行）：

```sql
-- diagram_engine 存在文档 outline JSONB 内，落库即证明引擎没挂
SELECT id, title,
       outline::text LIKE '%diagram_engine%' AS has_engine,
       substring(outline::text from '"diagram_engine": "[a-z]*"') AS engine
FROM ppt_documents
WHERE outline::text LIKE '%diagram_engine%'
ORDER BY created_at DESC LIMIT 5;
```
  `engine` 为 `graphviz`（本地 dot 排版，当前主路径）或 `mcp` 均算通过；**两行都查不到** = 图示页根本没触发，查日志 `grep -i drawio /data/justice/logs/server.log`。

## 模块四：自动配图（图库链路）

- **上传识别**：新建 PPT → 任务上下文上传 1-2 张真实的社区矫正/普法宣传照片。
- **合格标准**：
  1. 上传后照片卡片出现模型生成的画面说明（caption 非空）；
  2. 生成结果里图片落在带配图版面（如左图右文 `image_right`）；
  3. 图片**不拉伸变形**（实现是 crop-to-fill 裁切填充，`_add_picture_fill`）。
- **若图片没出现**：看导出响应 warnings 是否有「第N页所用图片已下架或删除」；再看该页 `image_id` 是否为空（35B 判定不相关时有权不放图，属正常行为，可换更贴合页面内容的照片重试）。

## 模块五：模板克隆（占位符替换）

- **自传模板**：准备带 `{{title}}` 和正文占位符的 `.pptx`。
- **上传前预检**（服务器或本地均可）：

```bash
python deploy/check_ppt_template.py <模板.pptx>   # 版式体检

```
- **填充测试**：下载后全文搜索 `{{`——**一个都不允许残留**；多栏文本对应入格、字号正确。
- **注意**：规整模板走几何克隆；装饰复杂的模板会按设计退可读兜底页（带模板配色），这不算失败——看该页是否保留了模板色板。
