## 一、加载页 Logo 白角 + 与打包 icon 不一致（已修）

**根因**（两条独立问题叠加）：
1. `AppLogo.kt` 内嵌的是**蓝色** WebP（256×256，**无 alpha 通道**）——圆角外的四角是白色像素，启动页深色背景上就显示为白色四角。
2. 打包用 `desktop/app_logo.ico` 是**红色**金徽标——两套完全不同的素材（蓝版最后更新于 25806a4，红版 ico 于 f7590b4 加入）。

**修复**：
- 从 ico 提取红色徽标，清理左下角「AI生成」水印（水印在透明区，231 像素置全透明），生成带 alpha 的 WebP 重新内嵌 → 启动页、窗口图标、exe 图标三处完全一致、四角全透明。
- `app_logo.ico` 重新生成为多尺寸（16/24/32/48/64/128/256），任务栏小尺寸更清晰。
- 启动页背景由亮蓝渐变改为品牌深藏青（`0xFF0E1F38 → 0xFF16263F`），与登录页/顶栏一致，红金徽标在深色上更突出。

## 二、生成后切换模板（已修，客户端 3 个真 bug + 服务端提速）

后端链路本身是闭环的（`save_draft` 写 `template_id` → preview 与异步任务都读 `doc.template_id`），问题全在客户端：

| # | 问题 | 修复 |
|---|------|------|
| 1 | `refreshPreview` 开头 `if (previewBusy) return`——预览渲染中切模板被**静默吞掉**（点了没反应） | 改为排队：当前渲染结束后按最新模板再渲染一轮 |
| 2 | 渲染期间 docId 变化时 `previewBusy` 永久卡 true，之后所有刷新/切模板全部失效 | busy 无条件放掉 |
| 3 | 异步生成 DONE 后**没有任何换模板入口**；`dismissJob` 回编辑也不刷新预览（看到的是生成前旧版式） | DONE 态新增模板下拉 + 「重新生成 PPT」按钮；`dismissJob` 强制刷新预览 |

**服务端提速**：`preview_document` 每次都全量渲染（pptx 渲染 + soffice 转 PDF + pdftoppm 转 PNG，数秒~数十秒）。新增结果缓存：按「大纲 + 模板 + 产物来源 + mtime」MD5 作 key，命中直接复用已渲染 PNG 秒回；渲染失败/降级不写 key，不影响重试。

新流程：生成完成 → 在 DONE 界面直接换模板 → 点「重新生成 PPT」（5–15 分钟重新出片，服务端按新模板渲染）；或「返回编辑」看到的就是真实产物预览，换模板即时重渲染预览，点「AI 生成 PPT」重新出片。
